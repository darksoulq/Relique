Relique Help

Commands

Relique provides a set of commands for opening the GUI, reloading configurations, and modifying player slot capacities. The base command is /relique.

Command List

Command

Permission

Description

/relique

relique.gui

Opens the relic equipment GUI for the executing player.

/relique reload

relique.reload

Reloads all slot configurations, entity mappings, icons, and language files, then rebuilds the resource pack.

/relique slot add <target> <slot> <amount>

relique.modify_slots

Increases the maximum capacity of the specified slot for the target player.

/relique slot remove <target> <slot> <amount>

relique.modify_slots

Decreases the maximum capacity of the specified slot for the target player. Overflowing items are automatically unequipped.

/relique slot set <target> <slot> <amount>

relique.modify_slots

Sets the exact capacity of the specified slot for the target player. Overflowing items are automatically unequipped.
