## Features

A Curios-like Plugin for PaperMC servers

- JSON based Slots
- Slot attributes supporting modifiers to increase limits
- All entities can have relics (defined in JSON)
- 5 Default slots (head, chest, ring, belt, charm)
- Builtin Attribute modifier and equip/unequip sound support
- API for custom slot validators and much more.

And much more.
